# ADR-008: AI Career Intelligence Engine

**Status:** Proposed\
**Target Phase:** Phase 3

## Context

HireRise aims to provide personalized career guidance driven by data and
AI.

## Decision

Implement a dedicated AI Career Intelligence Engine responsible for: -
Career Health Index (CHI) - Skill-gap analysis - Career path
recommendations - Salary intelligence - Learning recommendations

## Rationale

A dedicated engine separates business intelligence from application
workflows.

## Consequences

-   Modular AI architecture
-   Reusable intelligence services
-   Easier model evolution
