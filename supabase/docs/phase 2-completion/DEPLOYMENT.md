# Deployment Guide

## Preconditions

-   Clean working tree
-   Reviewed migrations
-   Backup verified
-   Production approval

## Deployment

1.  Pull latest certified branch.
2.  Apply migrations.
3.  Verify schema.
4.  Validate application health.
5.  Confirm logs and metrics.

## Rollback

Use approved rollback procedures where available and restore from
backups if required.
