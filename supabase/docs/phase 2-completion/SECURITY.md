# Security Policy

## Supported Releases

  Version                       Status
  ----------------------------- -----------
  v2.1.x-production-certified   Supported

## Reporting

Report security issues privately to the project maintainers. Do not
disclose vulnerabilities publicly until reviewed.

## Secure Development

-   Enable secret scanning.
-   Review authentication/authorization changes.
-   Verify RLS for protected tables.
-   Review migrations before production.
-   Validate dependencies regularly.
