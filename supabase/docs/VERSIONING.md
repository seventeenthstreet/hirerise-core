# Versioning Policy

HireRise follows Semantic Versioning with engineering release
governance.

## Format

`MAJOR.MINOR.PATCH[-qualifier]`

Example: - v2.1.0-production-certified - v2.2.0-beta - v2.2.1

## Meaning

-   MAJOR: breaking architectural changes
-   MINOR: new capabilities
-   PATCH: fixes and reconciliations

## Release Process

1.  Working tree clean.
2.  Production verified.
3.  Documentation updated.
4.  Annotated Git tag created.
5.  Release notes published.

## Current Baseline

`v2.1.0-production-certified`
